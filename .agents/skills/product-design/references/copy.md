# UI Copy & Microcopy Guidelines (Vercel Method)

Every word in an interface either builds trust or causes friction.

---

## 1. Rules for UI Text

* **Action-Oriented Buttons:** Use verbs describing what will actually happen:
  - Good: "Télécharger le PDF", "Créer un badge", "Vérifier la carte"
  - Bad: "Soumettre", "OK", "Continuer", "Valider"
* **Human-Centric Error Messages:**
  - Never dump raw stack traces, SQL errors, or code numbers (e.g. `PGRST116`).
  - Explain what happened in plain language and what the user can do next.
* **Positive Framing in Success Feedback:**
  - State the tangible achievement: "24 cartes générées en haute définition" instead of "Opération réussie".
* **Progressive Detail:**
  - Primary headline: 3 to 6 words.
  - Subtitle: 1 clear sentence explaining context.
